## 디버깅 사례

### 사례 1. `python -m unittest`가 테스트 0건으로 끝남 (D1)

- **증상**: `python -m unittest`가 `Ran 0 tests ... NO TESTS RAN`으로 종료됩니다. 계획서의 완료 기준(`python -m unittest` 통과)을 확인할 수 없었습니다.
- **조사**: `discover -s tests`는 통과했지만, 인자 없는 실행은 `tests`가 패키지가 아니어서 테스트를 찾지 못했습니다.
- **수정**: `src/__init__.py`, `tests/__init__.py` 추가. 이후 두 명령 모두 통과합니다.
- **교훈**: README의 실행 명령을 실제로 실행해 확인해야 합니다. 이 환경(Python 3.12)에서는 계획서에 적힌 `No module named 'src'` 오류가 재현되지 않았고, 대신 0건 실행 문제가 있었습니다.

### 사례 2. 테스트 파일 문법 오류 (셸 heredoc 이스케이프)

- **증상**: 테스트를 추가한 뒤 `SyntaxError: unterminated string literal (detected at line 32)`가 발생하고 테스트가 한 건도 실행되지 않았습니다.
- **원인**: Bash heredoc에서 Python 스크립트로 파일을 수정할 때 `\n` 이스케이프가 보존되지 않아, 문자열 안에 실제 줄바꿈이 들어갔습니다. 복구용 스크립트도 같은 이유로 실패했습니다.
- **수정**: 스크립트로 파일을 고치지 않고 파일 쓰기 도구로 전체를 다시 작성했습니다.
- **교훈**: 역슬래시가 많은 코드는 셸을 거치지 않고 파일로 직접 씁니다.

### 사례 3. `as_of` 테스트의 기대 날짜 오류

- **증상**: `AssertionError: '2026-10-30' != '2026-10-31'`
- **원인**: 테스트 데이터는 2026-08-01부터 91일치라 마지막 날이 10-30입니다. 기대값을 10-31로 잘못 적었습니다. **코드 결함이 아니라 테스트 오류**였습니다.
- **수정**: 기대값을 10-30으로 정정했습니다. 로직은 변경하지 않았습니다.

## 코드 리뷰에서 발견·수정한 결함 (P02)

| 결함 | 수정 |
|---|---|
| CSV 헤더 누락 시 `KeyError` | 누락 컬럼을 알려주는 `ValueError` |
| `nan`/`inf` 환율이 검증을 통과 | 유한한 양수가 아니면 거부 |
| 빈 CSV, 잘못된 값의 오류 위치 불명 | 빈 파일 거부, 행 번호 포함 메시지 |
| 괴리율 경계(-3/-7/-10%)가 부동소수점 오차로 어긋날 수 있음 | 소수 8자리 반올림 후 판정 |
| 입력 오류 시 traceback 출력 | `오류: ...` 메시지와 종료 코드 1 |

## 검증

- 부등호 변형(`<= -7`→`< -7`, `< -3`→`<= -3`, `<= -10`→`< -10`)을 하나씩 적용하면 경계 테스트가 매번 실패했습니다. 원래 코드로 복구했습니다.
